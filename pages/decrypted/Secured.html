ToolInfo Retrieval

POST /api/tooinfo//GetToolInfo

Description: Gets the tool info from user, group, package level.
Note: Response json may vary depending on the content of columns:
t_user_toolinfo [t_user_toolinfo_value]
t_user_toolinfo_grp [t_grp_toolinfo_value]

Request Body:

{
    "user_id":1,
    "tool_name": "GSheet",
    "info_key":"GSheet_ID"
}

Response: May vary depending on data

{
    "Name": "Budget",
    "SheetID": "1b9HeabcdeKxXjkxcQkEGb-5IvcG6NBUXeWcX6BjUxxxx"
}

Google Sheet API

POST /api/external/data/googlesheets/readfromsheet'

Description: Reads data from Google Sheet

Request Body:

{
  "SheetID":{
    "user_id": 999,
   "tool_name": "GSheet",
   "info_key":"GSheet_ID"
  },
  "SheetToken":{
    "user_id": 999,
   "tool_name": "GSheet",
   "info_key":"GSheet_Token"
  },
  "ReadParam":{
    "SheetName":"Budget",
    "Range":"B46:D48"
  }
}

Response: * results to 2D array

{
  "GSheet_Result": [
    [
      "Hygenic Kits",
      "1,000.00",
      "500.00"
    ],
    [
      "Food Supplement",
      "500.00",
      "500.00"
    ],
    [
      "Groceries",
      "7,500.00",
      "9,000.00"
    ]
  ]
}
POST /api/external/data/googlesheets/writetosheet'

Description: writes data to Google Sheet

Request Body:

{
  "SheetID":{
   "user_id": 1,
   "tool_name": "GSheet",
   "info_key":"GSheet_ID"
  },
  "SheetToken":{
   "user_id": 1,
   "tool_name": "GSheet",
   "info_key":"GSheet_Token"
  },
  "WriteParam":{
    "SheetName":"Budget",
    "Range":"A1",
    "CellValue":"TEST Write"
  }
}

Response: 

{
  "GSheet_Result": {
    "spreadsheetId": "1b9HeYFAAKxXjkxcQkEGb-5IvcG6****************",
    "updatedCells": 1,
    "updatedColumns": 1,
    "updatedRange": "Budget!A1"
  }
}
